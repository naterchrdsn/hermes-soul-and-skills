# Hermes Soul and Skills

A small public bundle of agent operating posture and reusable Hermes skills.

## Contents

- `SOUL.md` — a clean persona/operating document: direct, calm, useful, non-theatrical.
- `notes/soul-merge-proposal.md` — the merge rationale and draft that informed `SOUL.md`.
- `skills/software-development/systematic-debugging/SKILL.md`
- `skills/software-development/verification-before-completion/SKILL.md`
- `skills/software-development/preflight-checks/SKILL.md`
- `skills/productivity/session-recall-and-continuity/SKILL.md`
- `skills/github/github-pr-workflow/SKILL.md`
- `skills/github/github-repo-management/SKILL.md`

## Why these

This set is intentionally opinionated.

It favors skills that make agents more trustworthy and practically useful:

- **debug before guessing**
- **verify before claiming success**
- **run project checks before committing**
- **recover context instead of making the user repeat themselves**
- **handle GitHub repo and PR work with real operational discipline**

## Provenance

These files were curated out of a working Hermes environment and exported into a plain GitHub repo so they can be studied, borrowed, or adapted.
